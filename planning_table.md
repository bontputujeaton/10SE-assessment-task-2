# Planning Table
> The planning table runs through the order of operations and the planning undertaken. Planning is essential for designing and building games and it is useful for engineers create and think out each step of the project in.

|Step     |Why       |Expected Result   |Time    |
|---------|----------|------------------|--------|
|Game Mechanics Design     |I need to be able to explain **how** the game works before starting on design and development.     |Instructions on how the Top Trumps game is played, how a round works, what is required of the players.               |2 hours     |
|Data Selection and Game Attributes      |I need to know all the necessary attributes and methods I will need in order for the game to properly function.       |Selected attributes with long-sentence explanations on why I chose them.           |3 hours   |
|Class Design  |I need to determine the object-oriented structure of my game and find what objects are necessary to be programmed into my game in order for it to function.    |All attributes designed with data types. |2 hours  |
|Class Diagram |A UML class diagram is a core building block of Object-Oriented Programming (O.O.P), and is necessary in my project as they provide the overall blueprint to how I will design my game.   |A nicely-set out easy to understand UML Class Diagram, with correct relationship types and notation. |1 hour      |
|User Interface and Card Design |To demonstrate a design of the User Interface and display the card designs for the game.  |All designs complete, title screen, card layout, and user interface to be completed.       |3 hours   |
|Social, Ethical and Legal Implications  |To view thoughts on my game in a different perspective, take feedback and improve on the designing of my game. |Long-answer sentences answering questions on Social, Ethical and Legal Implications          |2 hours      |
